# scriptcavern.github.io
This repository is a website acting as a resume that has last been updated July 23rd, 2026.

In order to run the website, open the repository in GitHub Desktop and then in VS Code. Then, you can either run the program without debugging via the toolbar on the top-left (Run --> Run Without Debugging) or, if you have the Live Server extension installed on VS Code, simply right-click the HTML file and run it with Live Server.

Repository link: https://github.com/Primordion/scriptcavern.github.io
